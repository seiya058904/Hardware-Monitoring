采样对照各持续 180 秒，FPS 对照为 CSV 回放，不代表游戏帧率提升。更接近设定频率后，进程平均 CPU 从单核的 0.43% 增至 0.95%，不能声称总体 CPU 降低。

修改集中在采样节拍、FPS 百分位计算和成对快照、native 服务串行执行与退出、托盘消息的 Tk 线程边界、设置保存后的配置发布、设备故障状态及安装清单。设置切换复用 Toplevel，普通保存避免无故重启 PresentMon。LAN 页面保留现有布局，修复英文状态与目标进程，增加独立过期检查、焦点样式及手机 44 px 按钮。

首轮候选验证包括当时源码 59 项回归、语法检查、PyInstaller/NSIS 构建、实际 PresentMon 游戏帧采集、15 分钟源码运行及前一构建的 10 分钟打包运行。首轮 EXE 再经隔离安装、升级和 3 分钟运行，推进 175 个样本；native 托盘退出约 1.08 秒，PresentMon 和监听端口均已回收。该短会话目标无帧，游戏 FPS 数据来自前述长会话，不将无帧会话当作帧率性能数据。5 秒 native 采样阻塞测试中，UI 约 3.13 秒退出；传感器在调用返回后由所属线程释放，停止后没有发布新样本。浏览器在桌面、320/390 px 宽度下验证中英文、深浅主题、degraded、stale 和断开状态；请求阻塞时旧值会先隐藏。

首轮 1,018 个载荷文件逐项核对 SHA-256，安装占用拒绝、锁文件回滚、损坏清单拒绝、配置损坏备份和保存失败保留均通过。隔离卸载保留无关的 personal.txt 与运行时配置；允许留下空目录。首轮未覆盖原有 v1.0.8 注册信息和安装路径，后续正式升级见 RC 报告。默认配置与基线逐项相同，LAN 默认关闭且仅 GET；未修改防火墙、开机启动或远程配置。

首轮安装器的历史 SHA-256：`D7281ECF4258941E9BF9180A18B202DDB9854AF7EAA34621ED9A37C0364065DB`；首轮 EXE：`CE4E251956F107FEB43D989A99E6362E0F522CEFAE651D16DD70610050CEAE49`，文件版本 `1.0.13.0`。这些校验值不对应当前同名 RC 安装包；当前值见 RC 报告。

首轮验证边界：NSIS 完整流程当时使用独立名称、HKCU 和 user 执行级别，未覆盖原安装；正式 HKLM 升级及真实手机已在后续 RC 补验。首轮打包运行的传感器首次可用约 15.8 秒，随后一轮约 3.2 秒；可见混合负载运行记录过 6.63 秒心跳峰值，未用来宣称性能收益，其归因和剩余风险见 RC 报告。单机测试仍不能证明全天稳定、多 GPU 热插拔或其他显卡/权限环境。Android/Linux CI 未执行，Termux 未修改。
